# As telas

Uma pasta por tela, da T01 à T13, e o inventário (T00). Em cada uma:

| arquivo | o que diz |
| --- | --- |
| `tela.md` | a ficha: para que serve, o que tem, como se comporta |
| `estados.md` | a tabela de quadros e estados, uma linha por referência |
| `textos.md` | os textos exatos de cada referência, na ordem em que aparecem |
| `animacao.md` | o movimento |
| `referencias/html/` e `referencias/png/` | o desenho de cada referência, em HTML (para medir) e em PNG (para comparar) |

| tela | o que é |
| --- | --- |
| T01 | Entrar |
| T02 | Digite o código |
| T03 | Preparar o app |
| T04 | Bloqueado |
| T05 | Início |
| T06 | Paradas da viagem |
| T07 | Mapa |
| T08 | Outro ponto hoje |
| T09 | Notificações |
| T10 | Perfil |
| T11 | Avisos |
| T12 | Privacidade |
| T13 | Excluir conta |

São 145 referências: 13 telas, 59 momentos e 73 estados. As referências foram desenhadas com superfícies sólidas; o vidro está em `03-design-system/vidro/`, e as referências que mudaram por decisão estão em `06-prototipo/fotos/fidelidade/a-redesenhar.json`, com o porquê de cada uma.
