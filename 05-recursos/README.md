# Os recursos

| pasta | o que tem |
| --- | --- |
| `fontes/` | a fonte Inter, em cinco pesos (SIL Open Font License 1.1) |
| `icones/` | os 64 ícones, em SVG, da família Lucide (licença ISC) |
| `marca/` | a marca: o ícone do app, o pictograma vazado, o ícone da loja e a marca mobs2 |
| `readme/` | as imagens do README da raiz |

## A marca

| arquivo | o que é |
| --- | --- |
| `icone-app.svg` | o ícone do app, com o quadrado de fundo. É o que as referências desenhadas usam |
| `pictograma.svg` | o mesmo desenho, sem o quadrado e com os recortes vazados: as janelas, o letreiro, os faróis e os contornos são buracos. É o que o Entrar mostra no quadro de vidro, com as duas cores por token |
| `icone-loja.svg` | o ícone da loja: o desenho vazado sobre o fundo de luz do escuro |
| `icone-android-frente.svg`, `icone-android-fundo.svg`, `icone-monocromatico.svg`, `icone-pequeno.svg`, `icone-app-notificacao.svg`, `icone-app-folha06.svg` | os derivados do ícone desenhado |
| `mobs2.svg` | a marca mobs2, da assinatura |
